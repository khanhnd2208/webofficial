The 960×960 WebP sheets use the game's seven-mood cell order. Each GIF is a 192×192, roughly four-second timing sketch: idle → roar → inhale → chomp → laugh → hurt → defeated → idle. The pose transitions deliberately remain simple; these are for choosing a direction, not final in-game animation. The image generation tool made the three base sheets from the screenshot. `cwebp` resized and compressed them; `ffmpeg` assembled the GIFs. All six files stay below 1 MB and the WebP sheets below 300 KB.
