Expert Agent Instructions

Review Brief

  1. Review as a UI/UX expert agent for a public professional website.
  2. Prioritize mobile experience at 320px, 375px, 390px and 768px, then desktop at 1024px and 1440px.
  3. Assess visual hierarchy, conversion clarity, credibility proof, accessibility, interaction states and content density.
  4. Flag concrete issues with route, section, viewport and expected user impact.
  5. Do not invent performance or conversion data. Treat unverified KPI gaps as content/evidence gaps.
  6. Recommend fixes using the existing editorial premium direction, not a complete brand reset.

Primary Questions

What To Judge

  1. Does the editorial premium direction build expert credibility within the first viewport?
  2. Is the mobile hero order effective enough for conversion, or should the image be compressed further?
  3. Are service choices clear for first-time visitors who do not know which offering they need?
  4. Do project cards and case studies provide enough proof when hard KPIs are intentionally limited?
  5. Are CTA labels and destinations specific enough for high-quality inquiries?
  6. Does the contact form collect enough context without creating unnecessary friction?
  7. Are motion, focus, contrast and touch targets consistent with WCAG 2.2 AA expectations?
  8. Where should real photos, artefacts or testimonials replace current placeholder/editorial imagery first?

Layout: constrained shell, border-separated bands, card use limited to repeated evidence/form elements.

Conversion: contact CTAs appear in hero, service sections, case studies and final page bands.
Accessibility: visible labels, focus-visible rules in CSS, dialog trap in mobile menu, field-level form errors.

export type AnalyticsEvent = (typeof ANALYTICS_EVENTS)[number];

export type AnalyticsPayload = {
	slug?: string;
	type?: string;
	sourcePage?: string;
	label?: string;
};

declare global {
	interface Window {
		umami?: {
			track: (event: string, data?: Record<string, string>) => void;
		};
	}
}

export function isAnalyticsEvent(value: string): value is AnalyticsEvent {
	return (ANALYTICS_EVENTS as readonly string[]).includes(value);
}

export function trackEvent(event: AnalyticsEvent, payload: AnalyticsPayload = {}): void {
	if (typeof window === 'undefined') return;
	if (!isAnalyticsEvent(event)) return;

	const data: Record<string, string> = {};
	if (payload.slug) data.slug = payload.slug;
	if (payload.type) data.type = payload.type;
	if (payload.sourcePage) data.sourcePage = payload.sourcePage;
	if (payload.label) data.label = payload.label;

	try {
		window.umami?.track(event, Object.keys(data).length ? data : undefined);
	} catch {
		// analytics must never break UX
	}
}
