# Source Serif 4

Unmodified Google Fonts TTF distributions (v14), licensed under SIL OFL 1.1; see
OFL.txt. These include the full character set, including Vietnamese. We bundle
the 300, 400, 600 and 700 weights used by the public message layout so release
builds do not depend on Google returning font URLs that Turbopack can parse.

Source: https://fonts.googleapis.com/css2?family=Source+Serif+4:wght@300;400;600;700&display=block
